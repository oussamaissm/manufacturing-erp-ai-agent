# Item Code Catalog

Item codes are written in capitals with hyphens: FAMILY-DETAIL (e.g. STEEL-BAR-20 is steel bar, 20 mm). Always use the exact code in the ERP. Use the item name to find a code if you are unsure.
Stock levels and safety stock are NOT listed here: they change daily and live in the ERP.
