# Machine Registry

All machines are workstations in the ERP. Use the exact machine name (for example CNC-01) when asking for machine status.

| Machine | Description | Role |
|---|---|---|
| CNC-01 | CNC milling centre, 3-axis | 3-axis milling of gear shafts and valve bodies |
| CNC-02 | CNC milling centre, 5-axis | 5-axis milling for complex aerospace parts such as turbine hubs; shared machine where Hexa Aero is scheduled first |
| PRESS-01 | Hydraulic press 200t | 200 tonne hydraulic press for pressing operations |
| LATHE-01 | CNC lathe | turning of shafts and rods |
| PACK-01 | Packaging line | packaging line for finished goods |
| CNC-03 | CNC milling centre, 4-axis | 4-axis milling of pump housings and manifolds; may run unattended at night |
| LATHE-02 | CNC lathe, twin-spindle | twin-spindle turning of flanges and cylinder rods |
| PRESS-02 | Hydraulic press 100t | 100 tonne hydraulic press |
| GRIND-01 | Surface grinder | surface grinding of turbine hubs |
| WELD-01 | Robotic welding cell | robotic welding of brackets; may run unattended with light barriers |
| PAINT-01 | Powder coating booth | powder coating of brackets and flanges |
| SAW-01 | Band saw cutting station | cutting bar and sheet to length |
| QC-01 | Coordinate measuring machine (quality lab) | coordinate measuring machine in the quality lab |
| ASSY-01 | Assembly bench line | assembly of hydraulic cylinders and manifolds |
| PACK-02 | Palletising robot | palletising robot at the end of the packaging line |

## Maintenance documents by machine family

- CNC-01, CNC-02, CNC-03: CNC milling maintenance procedure.
- LATHE-01, LATHE-02: lathe operation and maintenance.
- PRESS-01, PRESS-02: hydraulic press troubleshooting and hydraulic oil change procedure.
- WELD-01, PAINT-01: welding and powder-coating cell guidelines.
- QC-01: measuring instrument calibration.
- All machines: lockout-tagout safety procedure and incident response.
